# Lowdown Documentation

Lowdown is a read-only terminal companion for following local Codex sessions.
It shows a live feed of short model summaries, with the original updates and
latest answer available to read in full.

- [Quickstart](quickstart.md): install, commands, keyboard controls and model settings.
- [Installation](install.md): verify, install, upgrade, roll back and remove binaries.
- [Input contract](input-contract.md): supported rollout format, discovery and limitations.
- [0.1.0 candidate](releases/0.1.0.md): features, limitations and publication checklist.
- [Release guide](ops/releasing.md): tests, platform checks and archive distribution.
