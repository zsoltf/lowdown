# Lowdown 0.1.0 Release Candidate

Status: preparation only. This document is not an announcement of publication
or completed platform verification.

Lowdown is a standalone, read-only Rust CLI for following local Codex rollout
sessions. Run `lowdown` from a project to see a live feed of short model
summaries, with full original messages and the latest answer available to read.

## Included

- Recent updates first, background history loading, and session switching.
- Batched Codex CLI summaries using `gpt-5.6-luna` with `none` reasoning.
- Disk-cache reads independent of model calls and instant recent-session reuse.
- Keyboard navigation, paging, expandable readers, wrapping, and local times.
- Text digest and JSON recent-updates commands for explicit non-TUI use.

See [installation](../install.md) and [controls](../quickstart.md).

## Limits

Only the documented Codex rollout JSONL family is supported. Summary generation
uses your existing Codex CLI account and may consume subscription usage. Raw
text remains usable without model access; summaries are not verified facts.

The feed contains progress messages, not final answers. Only the latest final
answer has a separate reader. Project switching requires restarting from a
different directory; sessions discovered after startup require a restart.
Large or sparse logs can still need substantial tail scans. Digest reads the
full file and uses heuristics, not a whole-task model synthesis.

No menu-bar app, Runwai integration, daemon, dashboard, or additional provider
adapter is included. [Full input contract](../input-contract.md).
